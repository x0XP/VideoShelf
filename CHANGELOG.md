# VideoShelf changelog

## 1.7 series — September 2026

- Rebuilt the desktop interface around the current VideoShelf/Xdolf-inspired design.
- Added seeded online discovery with filtering, artwork previews and file inspection.
- Added local torrent downloading and in-app streaming with the bundled transfer/player runtime.
- Added automatic update checks, verified installers and clean in-place runtime replacement.
- Improved torrent metadata discovery, stream startup reliability and updater behaviour.
- Improved DuckDuckGo artwork lookup with episode-aware and search-context-aware queries, caching and original-image preference.
- Results reporting zero seeders remain excluded from the online list.

## Earlier milestones

- **1.6** — Added local download and embedded streaming.
- **1.5** — Introduced the current dark VideoShelf visual system.
- **1.4** — Added in-app collection/folder creation and display-name aliases.
- **1.3** — Added cached image previews for online results.
- **1.2** — Added online discovery and filtering.
